\# Excel State Extractor Formula

A simple Excel formula utility for extracting U.S. state abbreviations from address strings automatically.

Useful for:

\- Dispatch workflows

\- Excel automation

\- Address data cleaning

\- CRM spreadsheets

\- Lead processing

\## Formula

```excel

=MID(A1, FIND(",", A1) + 1, 2)

```

\## Example

\### Input

```text

123 Main Street, TX

```

\### Output

```text

TX

```
